# Task Manager API

A small REST API for managing personal tasks, built with TypeScript, Express,
and SQLite.

## Requirements

- Node.js 24 or newer
- npm

## Development

```sh
npm install
npm run dev
```

The API listens on port 3000 by default. `GET /health` is available as a basic
process health check.

```sh
npm test
npm run build
```
